# PhoneAI

Локальный Android AI-ассистент, который использует вычислительные ресурсы телефона.

## Восстановление проекта

Этот репозиторий создан как отдельный дом для PhoneAI. Рабочая база PhoneAI Core 0.16 была восстановлена из проверенной сборки и переносится сюда из временной диагностической ветки.

Текущие компоненты базы:
- локальная LLM через llama.cpp;
- локальное распознавание речи через whisper.cpp;
- wake-word / KWS через sherpa-onnx;
- Android-проект на Kotlin/Gradle;
- CPU-сборка без обязательного OpenCL.

Следующий этап: импортировать восстановленные Android-исходники в обычную структуру репозитория, затем продолжить разработку экрана чата, вложений, истории чатов и поддержки саха.
